# WNBA Color Fix

Este paquete mantiene WNBA sin EV/cuotas y mejora solo la estética funcional:

- Colores por equipo WNBA.
- Fondo con gradientes suaves.
- Cards de partidos con colores de local/visitante.
- Lista de jugadoras con color por equipo.
- Página de jugadora con header de equipo.
- Filtros visibles: rival, localía, minutos, lado.
- Botones de métricas con colores por stat.
- Gráfico de barras propio con línea, hits verdes y fallos rojos.
- No modifica NBA.

Archivos incluidos:
- app/wnba/page.tsx
- app/wnba/players/page.tsx
- app/wnba/players/[playerId]/page.tsx
- components/wnba/WNBAPlayerChartPanel.tsx
- components/wnba/wnbaTeamColors.ts
